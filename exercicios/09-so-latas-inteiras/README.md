# 09 · Só latas inteiras

App: **Docinhos** · Conceito: `Switch` e `ceil` · ⏱ 10 min

Abra esta pasta no Android Studio (**File › Open**). A explicação está no módulo 9 do curso.

## Como começa

O interruptor "Só latas inteiras" está na tela, mas não liga.

## Tarefa

1. Crie o estado `latasInteiras`, que começa em `false`, e ligue o `Switch` a ele.
2. Dê a `calcularLatas` um segundo parâmetro, `inteiras: Boolean`. Quando for verdadeiro, arredonde para cima com `ceil`.
3. Passe `latasInteiras` na chamada de `calcularLatas`.

## Resultado

Com 20 convidados: 2,7 latas com o interruptor desligado e 3 com ele ligado.
