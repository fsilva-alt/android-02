# 03 · Um prato para cada número

App: **Prato do Dia** · Conceito: `when` · ⏱ 8 min

Abra esta pasta no Android Studio (**File › Open**). A explicação está no módulo 3 do curso.

## Como começa

O nome muda a cada sorteio, mas a imagem é sempre a do brigadeiro.

## Tarefa

1. Troque o valor fixo de `imagem` por um `when (prato)`.
2. Use a mesma ordem do `when` de `nome`: 1 brigadeiro, 2 pão de queijo, 3 bolo de cenoura, 4 pudim, 5 coxinha e, no `else`, açaí.

## Resultado

A imagem e o nome sempre combinam.
